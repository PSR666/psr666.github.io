# Shurui Peng · 彭书睿

Academic homepage: https://psr666.github.io/

A responsive, bilingual personal website built with HTML, CSS, and JavaScript. No build step, external fonts, analytics, or third-party JavaScript is required.

## Local preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open http://127.0.0.1:8765/.

## Update the site

- Edit `index.html` for publications, education, links, and contact information.
- Update the matching English and Chinese text in `script.js`.
- Edit `style.css` for layout, type, colors, and responsive behavior.
- Add publication illustrations to `assets/`.
- Push to `main`; GitHub Pages serves the repository root.
